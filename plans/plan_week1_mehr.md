# 🗓️ برنامهٔ هفتگی مرشد — هفتهٔ اول مهر (۴ تا ۱۰ مهر ۱۴۰۵)

> فاز: **جبران بک‌لاگ با تمام توان** · بدون کلاس زنده (کلاس‌ها را هفته‌های بعد آنلاین/ضبطی می‌بینی)
> هدف بزرگ: آماده‌سازی برای اولین آزمون **۱۷ مهر**
> اولویت درس‌ها (زیاد→کم): **فیزیک ← حسابان ← شیمی ← هندسه ← گسسته**
> بودجهٔ مطالعهٔ هفته: ~۵۵ ساعت خالص | این هفته: **۱۶ جلسهٔ ویدیو** + تست + یک آزمون جمعه

---

## 🎯 استراتژی تقسیم زمان (چرا اینطوری؟)
- هر جلسه = **تماشای ۲x + توقف برای حل مثال (~۱.۵ ساعت)** + **جزوه‌نویسی و تست تثبیتی (~۱ ساعت)**.
- درس‌ها را **در هم می‌بافم** تا خستگی نگیری (مثلاً پشت‌سرهم ۵ تا فیزیک نه).
- **تست صبحگاهی هر روز = مرور اسپیس‌ریپیتیشن** دیروز/پریروز (۱-۳-۷).
- **پنجشنبه** = روز پرقدرت (۴ جلسه). **جمعه** = آزمون شبیه‌سازی + تحلیل + ۲ جلسه.

### سهم هر درس این هفته
| درس | استاد | جلسات این هفته | باقی‌ماندهٔ بک‌لاگ بعد از هفته |
|-----|-------|----------------|------------------------------|
| فیزیک۳ | شجاعی | ج۱ تا ج۵ (۵ جلسه) | ~۴ جلسه |
| حسابان۲ | کرمی | ج۱ تا ج۴ (۴ جلسه) | ~۶ جلسه |
| شیمی۳ | هادیان‌فرد | ج۱ تا ج۴ (۴ جلسه) | ~۹ جلسه |
| هندسه۳ | واعظین | ج۱ (۱ جلسه) | ~۳.۵ جلسه |
| گسسته | انصاری | ج۱ تا ج۲ (۲ جلسه) | ~۳.۵ جلسه |

---

## 📅 برنامهٔ روزبه‌روز

### شنبه ۴ مهر — استارت هفته (۶ ساعت)
- ۰۶:۰۰ ورزش · ۰۶:۲۰ تست سبک تشخیصی ریاضی (۳۰د) · ۰۶:۵۰–۱۵:۰۰ مدرسه · ۱۵:۰۰ چرت+نهار
- 🟡 ۱۶:۰۰–۱۷:۳۰ **فیزیک ج۱** حرکت‌شناسی/مفاهیم پایه (شجاعی) — تماشا ۲x + حل مثال
- 🟢 ۱۷:۴۰–۱۹:۱۰ فیزیک ج۱ — جزوه + تست تثبیتی (۱۰تایی)
- 🟡 ۱۹:۴۵–۲۱:۱۵ **حسابان ج۱** یادآوری + تعیین علامت (کرمی) — تماشا
- 🟢 ۲۱:۲۵–۲۲:۳۰ حسابان ج۱ — جزوه + چند تست
- ۲۲:۳۰ مرور + برنامهٔ فردا

### یکشنبه ۵ مهر (۶ ساعت)
- صبح تست: **مرور فیزیک ج۱** (اسپیس ۱روزه)
- 🟡 ۱۶:۰۰ **حسابان ج۲** تعیین علامت پیشرفته (کرمی) — تماشا
- 🟢 حسابان ج۲ — جزوه + تست
- 🟡 **شیمی ج۱** (هادیان‌فرد) — تماشا
- 🟢 شیمی ج۱ — جزوهٔ سبک

### دوشنبه ۶ مهر (۶ ساعت)
- صبح تست: **حسابان ج۱-۲** (اسپیس)
- 🟡 **فیزیک ج۲** سرعت متوسط/لحظه‌ای (شجاعی) — تماشا
- 🟢 فیزیک ج۲ — جزوه + تست
- 🟡 **گسسته ج۱** بخش‌پذیری/قضیهٔ تقسیم (انصاری) — تماشا
- 🟢 گسسته ج۱ — جزوه + تست

### سه‌شنبه ۷ مهر (۷ ساعت)
- صبح تست: **شیمی + گسسته** (اسپیس)
- 🟡 **هندسه ج۱** ماتریس و ضرب ماتریس (واعظین) — تماشا
- 🟢 هندسه ج۱ — جزوه + تست
- 🟡 **شیمی ج۲** (هادیان‌فرد) — تماشا
- 🟢 شیمی ج۲ — جزوه
- 🔵 ۱ ساعت آخر: تست ترکیبی فیزیک (تثبیت)

### چهارشنبه ۸ مهر (۷ ساعت)
- صبح تست: **فیزیک + هندسه** (اسپیس)
- 🟡 **حسابان ج۳** معادلهٔ درجه۲ (کرمی) — تماشا
- 🟢 حسابان ج۳ — جزوه + تست
- 🟡 **فیزیک ج۳** شتاب (شجاعی) — تماشا
- 🟢 فیزیک ج۳ — جزوه + تست
- 🟣 ۱ ساعت آخر: مرور دفتر اشتباهات + تست گسسته

### پنجشنبه ۹ مهر — روز پرقدرت (۱۲.۵ ساعت · ۴ جلسه)
- صبح تست: مرور سبک کل هفته
- 🟡 **فیزیک ج۴** حرکت با شتاب ثابت (شجاعی) — تماشا + جزوه + تست
- 🟡 **شیمی ج۳** (هادیان‌فرد) — تماشا + جزوه
- 🟡 **حسابان ج۴** نامعادلات (کرمی) — تماشا + جزوه + تست
- 🟡 **گسسته ج۲** ب.م.م / هم‌نهشتی (انصاری) — تماشا + جزوه + تست
- 🟣 بلوک آخر: تست ترکیبی + دفتر اشتباهات

### جمعه ۱۰ مهر — آزمون + جمع‌بندی (۱۲.۵ ساعت)
- 🔵 صبح: **آزمون شبیه‌سازی** از مباحث کل هفته (فیزیک ج۱-۴، حسابان ج۱-۴، شیمی ج۱-۳، هندسه ج۱، گسسته ج۱-۲) — زمان‌دار ~۳ ساعت
- 🟣 تحلیل کامل آزمون + دفتر اشتباهات (~۱.۵ ساعت)
- 🟡 **فیزیک ج۵** (شجاعی) — تماشا + جزوه
- 🟡 **شیمی ج۴** (هادیان‌فرد) — تماشا + جزوه
- 🟣 مرور اشتباهات هفته + ساخت برنامهٔ هفتهٔ دوم

## 📌 نکات کلیدی
1. **قانون استارت:** هر روز فقط بلوک اول را شروع کن؛ موتور که روشن شد، خودش می‌کشه.
2. **تست ۱۰تایی:** ۱۰تا بزن → همان‌جا بررسی (✅⚠️❌) → ❌ به دفتر اشتباهات.
3. **زمان‌دار نه، تثبیتی آری** (فاز یادگیری). زمان‌دار از بهمن.
4. آزمون جمعه ساعت دقیقش هنوز TBD — اگر ماز/قلم‌چی واقعی بود، جای آزمون شبیه‌سازی می‌نشیند.
5. متریک هفته: **بهتر از هفتهٔ قبل** (هفتهٔ قبل صفر بود؛ این هفته هر جلسه = برد).
