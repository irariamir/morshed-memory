## این ریپو چیست؟
این «مغز و حافظهٔ» مرشد است — دستیار برنامه‌ریزی درسی آریامیر. تمام اطلاعات، برنامه‌ها، تحلیل‌ها و هویت بصری اینجا ذخیره می‌شود تا:
1. **حافظه دائمی و قابل‌حمل** باشد (مستقل از هر چت یا مدل هوش مصنوعی).
2. اگر لازم شد کار به **هوش مصنوعی دیگری** سپرده شود، فقط با دادن آدرس این ریپو، او بتواند دقیقاً مثل مرشد مسیر را ادامه دهد.

## 🚀 شروع سریع (برای هر AI جدید)
> اگر تو یک هوش مصنوعی هستی که تازه این ریپو به تو داده شده:
> **اول [`docs/HANDOFF.md`](docs/HANDOFF.md) را کامل بخوان.** آنجا همه‌چیز توضیح داده شده.

## 📂 ساختار
```
morshed-repo/
├── README.md                  ← همین فایل
├── docs/
│   ├── HANDOFF.md             ← ⭐ راهنمای کامل انتقال به AI دیگر (اول این را بخوان)
│   ├── SYSTEM_PROMPT.md       ← شخصیت و قوانین مرشد (پرامپت اصلی)
│   └── TELEGRAM.md            ← راهنمای ربات و کانال‌های تلگرام
├── memory/
│   ├── student_profile.md     ← ⭐ پروندهٔ کامل آریامیر (منبع حقیقت)
│   └── progress_log.md        ← لاگ روزانه/هفتگی پیشرفت
├── plans/
│   ├── plan_YYYY-MM-DD.md     ← برنامه‌های روزانه (متن)
│   └── cards/                 ← عکس کارت برنامه‌ها (برندشده)
├── brand/
│   ├── BRAND.md               ← هویت بصری (رنگ، فونت، لوگو)
│   ├── fonts/                 ← فونت کلمه + ایران‌یکان
│   └── logo-*.png             ← لوگوهای AR
└── scripts/
    └── make_card.py           ← سازندهٔ عکس کارت برنامه
```
